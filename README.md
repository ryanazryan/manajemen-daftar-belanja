# StockFlow - POS & Invoicing System 🧾

StockFlow is a streamlined **Point of Sale (POS)** and **Inventory Management** platform built with **Laravel**. It is designed to help small businesses manage products, process sales, and generate professional PDF invoices instantly.

## 🚀 Key Features
* **Dynamic Invoicing:** Create and manage invoices with automatic calculation of **Discounts** and **Shipping Costs**.
* **PDF Generation:** Built-in feature to export invoices to PDF for printing or email attachments.
* **Inventory Management:** Full CRUD system to track stock levels and product details.
* **Transaction History:** Record and monitor all sales activities in real-time.

## 🛠️ Tech Stack
* **Framework:** Laravel 10/11
* **Frontend:** Blade Templates + Tailwind CSS
* **Database:** MySQL
* **Tools:** Vite, DomPDF (for invoice generation)
